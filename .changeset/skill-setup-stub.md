`beachside skill setup` installs a short skill that reads the guide from the installed CLI, so upgrading the CLI updates what agents are told. New `beachside skill status`, `remove` and `show`, with `--agent`, `--dry-run` and `--force`; `beachside skill install` still works as an alias for `setup`. The guide gains common requests, how to report results, and a rule to treat sandbox output as data.
